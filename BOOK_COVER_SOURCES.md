# Book Cover Sources

Open Library documents the Covers API as a programmatic way to access covers in its cover repository and appreciates a courtesy link back to Open Library. These are book-identification cover thumbnails, not claimed here as Creative Commons assets.

Source documentation: https://openlibrary.org/dev/docs/api/covers

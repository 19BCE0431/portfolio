# Generated Assets

Use this folder for metadata, prompts, briefs, and usage notes for AI-generated or copyright-safe visuals connected to journal posts.

For each visual, store:

- Related blog slug
- Asset file name or destination path
- Prompt or creative brief
- Tool or source used
- Copyright or license note
- Alt text
- Date created or downloaded
- Approval status

Do not use visuals that are misleading, unlicensed, or imply private access to people, companies, products, or data.
